Der Ton startet nach dem Klick

Rev 2.0 · Panel nach dem Plan

  • Panel 60 × 42 cm mit echten Bauteilgrößen (7"-Display 15,4 × 9,2 cm, Pads 3,6 × 3,3 cm, Touchpad 8,6 × 7,9 cm). Zwischen allen Reglern mind. 1,5 cm.
  • VALUE / PATTERN: im Normalzustand Pattern wechseln (SHIFT = 10er), in Menüs und Display-Seiten = Wert. Menüs gehen nicht von selbst weg – EXIT drücken.
  • BPM im Menü: SHIFT + TAP öffnet es. SHIFT + REC = Resample. SHIFT + MFX = MFX-Typ, SHIFT + ROLL = Roll-Typ (jeweils VALUE).
  • SHIFT + <PAGE = UNDO, SHIFT + PAGE> = REDO (60 Schritte).

Pads · Bars · Solo · Okt. Send

  • Funktionsreihe: <P P> (Part), MUTE, ERASE, TRIGGER, SEQU., KEYB., CHORD, STEP JUMP. SHIFT + SEQU. = FILL, SHIFT + <P = COPY (Pad = einfügen), SHIFT + ERASE = Pattern leeren.
  • Pad im TRIGGER-Modus = Part spielen, das Display zeigt die Welle. Pad halten während PLAY = Sequenz des Parts pausiert.
  • ◁ − / ▷ +: Takt wählen (blaue LEDs = Bars). SHIFT = Länge.
  • OKT − / OKT + (über den rechten Pads): Oktave des aktuellen Parts (rote LEDs). In KEYB./CHORD = Tastatur-Oktave. SHIFT = Halbton.
  • SOLO gedrückt halten + Pads = nur diese Parts (auch wenn gemutet). Dabei OKT −/+ = Oktave der Solo-Parts. Loslassen = alles wie vorher. SHIFT + SOLO = DROP.
  • OKT. SEND (im MIX-Block) tippen = aktueller Part an/aus, halten + Pads = mehrere Parts. OKT. SEND halten + OKT −/+ (oder ◁ ▷) = Oktave aller Send-Parts runter/hoch. Parts mit CUTOFF 0, LEVEL 0 oder MUTE werden nicht gepitcht.

Sound

  • SYNTH OSCILLATOR 1:1 wie Korg EMX: TYPE mit 16 Typen (WAVEFORM, DUAL OSC, CHORD, UNISON, RING MOD, OSC SYNC, CROSS MOD, VPM, WS, ADDITIVE, COMB, FORMANT, NOISE, PCM+COMB, PCM+WS, AUDIO IN+COMB), OSC EDIT 1 + 2. Die WAVE wählt VALUE, solange die OSC-Seite offen ist (bei PCM-Typen = Sample). SHIFT + OSC EDIT 1 = DRUCK.
  • SAMPLE-Regler (der zuletzt gedrehte von SAMPLE/TYPE spielt), PITCH (SHIFT = GLIDE), START POINT = Sample-Start.
  • AMP EG · ADSR: ATTACK, DECAY, SUST., RELEASE = X-Achse (Zeit), mit SHIFT = Y-Achse: Attack-Pegel, Decay-Pegel, Sustain-Pegel, Release-Kurve. SUST. ohne SHIFT = Zeit vom Decay- zum Sustain-Pegel. Drehen öffnet EG EDIT im Display (9 Punkte zum Ziehen inkl. Delay, Hold, Kurven).
  • FILTER: TYPE, RESONANCE, EG INT, CUTOFF (SHIFT + TYPE = TRACK). MODULATION: TYPE, SPEED, EG TIME (Zeit der EG-Typen), DEPTH.
  • PARAMETRIC EQ: LOW, MID, HIGH (Gain), FREQ (Frequenz des gewählten Bands), MIX. BW an = die Regler stellen die Bandbreite ein, bis BW wieder gedrückt wird (LOW/HIGH ganz links = Shelf). Drehen öffnet die EQ-Seite im Display – dort Punkte ziehen, Preset und BW antippen. SHIFT + BW = Preset: 30 Hz + 18 kHz Cut, 40 Hz + 18 kHz Cut, Old Telephone, Kick.
  • TUBE · OUTPUT: T.MIX, A, B (Röhren-Drive), T.ON (SHIFT = alle), MASTER, PHONES. 3 × ECC82 unter der Haube.
  • MIX: SIDECHAIN (SHIFT = Quelle), GLUE DRIVE, BASS GLUE, MFX SEND, ROLL SEND. INSERT FX: TYPE, EDIT, − / +, 1–5.

Im Menü (kein Platz auf dem Panel)

  • PATTERN SET: BPM, MFX TYPE, ROLL TYPE, MOTION PLAY, ACCENT, Swing, Length, Beat, Key, Scale, Chord Set, Gate Arp, Chain …
  • PART EDIT: WAVE, AMP EG an/aus, SUSTAIN, RELEASE, EG DELAY, EG HOLD, DRUCK, OKT. SEND, EQ PRESET, EQ DRIVE, HIGH CUT, LOW CUT, STRETCH LENGTH in Steps, Loop Every, Glide, Oktave …
  • STEP EDIT (ganz im Menü), SAMPLE EDIT (Start, End, Loop, Level, Tune, Reverse, Punch), PART UTILITY (Copy, Clear, Fill All Parts …), INPUT (Audio-In, Sample 1 Bar), GLOBAL (Metronom, TX Character …).

Touchpad & Sync

  • Touchpad mit 4 Tasten: GATE ARP, T.SCALE, MFX, HOLD. MIDI, Clock, Audio-In über die Leiste oben.
