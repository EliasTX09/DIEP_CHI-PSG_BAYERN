Der Ton startet nach dem Klick

Rev 2.0 · Panel nach dem Plan

  • Panel 60 × 42 cm mit echten Bauteilgrößen (7"-Display 15,4 × 9,2 cm, Pads 3,6 × 3,3 cm, Touchpad 8,6 × 7,9 cm). Zwischen allen Reglern mind. 1,5 cm.
  • VALUE / PATTERN: im Normalzustand Pattern wechseln (SHIFT = 10er), in Menüs und Display-Seiten = Wert. Menüs gehen nicht von selbst weg – EXIT drücken.
  • BPM im Menü: SHIFT + TAP öffnet es. SHIFT + REC = Resample. SHIFT + MASTER FX = Master-FX-Typ, SHIFT + ROLL = Roll-Typ (jeweils VALUE).
  • Unten links in einer Reihe: TAP, REC, STOP, PLAY/PAUSE, SHIFT, ROLL, SOLO, TEMPO LOCK. Alle Beschriftungen stehen unter der Taste, die SHIFT-Funktion (blau) darüber.
  • SHIFT + <PAGE = UNDO, SHIFT + PAGE> = REDO (60 Schritte).

Pads · Bars · Solo · Octave Send

  • Funktionsreihe: ◀ PART / PART ▶, MUTE, ERASE, TRIGGER, SEQUENCER, KEYBOARD, CHORD, STEP JUMP. SHIFT + SEQUENCER = FILL, SHIFT + ◀ PART = COPY (Pad = einfügen), SHIFT + ERASE = Pattern leeren.
  • Pad im TRIGGER-Modus = Part spielen, das Display zeigt die Welle. Pad halten während PLAY = Sequenz des Parts pausiert.
  • Rechts über den Pads: ◀ BAR · OCTAVE − · OCTAVE + · BAR ▶. BAR = Takt wählen (blaue LEDs), SHIFT = Länge. OCTAVE = Oktave des aktuellen Parts (rote LEDs), in KEYBOARD/CHORD = Tastatur-Oktave, SHIFT = Halbton.
  • SOLO gedrückt halten + Pads = nur diese Parts (auch wenn gemutet). Dabei OCTAVE −/+ = Oktave der Solo-Parts. Loslassen = alles wie vorher. SHIFT + SOLO = DROP.
  • OCTAVE SEND (im MIX-Block) tippen = aktueller Part an/aus, halten + Pads = mehrere Parts. OCTAVE SEND halten + OCTAVE −/+ (oder BAR) = Oktave aller Send-Parts runter/hoch. Parts mit CUTOFF 0, LEVEL 0 oder MUTE werden nicht gepitcht.

Sound

  • SYNTH OSCILLATOR 1:1 wie Korg EMX-1: 16 Typen mit zusammen 258 Oszillator-Kombinationen. TYPE springt direkt zu einem Typ (WAVEFORM, DUAL OSC, CHORD, UNISON, RING MOD, OSC SYNC, CROSS MOD, VPM, WS, ADDITIVE, COMB, FORMANT, NOISE, PCM+COMB, PCM+WS, AUDIO IN+COMB). Das WAVE-Rad dreht am Stück durch alle 258 und wechselt dabei von selbst in den nächsten Typ: SAW … SIN, DUAL OSC SAW+SAW … SIN+NS, UNISON 3SAW … 6SIN, VPM, ADDITIVE … bis zu den 76 PCM-Wellen der EMX (PIANO, E.PIANO, CLAV, M1-ORGAN … STRINGS, GITARREN, BÄSSE, SYNSIN, DIGI, RAVEHIT1-6, Chord Sets, Drum Sets – nachgebaut, gleiche Namen und Reihenfolge wie im EMX-Handbuch). SHIFT = 10er-Schritte. Die blaue Anzeige zeigt Typ, Position (z. B. 165/258) und Welle, das 7"-Display die Liste davor/danach. Chord Sets (CH-…): die Oktave wählt den Akkord (Dur, Moll, Maj7, min7). Drum Sets (DR-…): jeder Ton ist ein anderer Drum-Sound. OSC EDIT 1 + 2 = die zwei Parameter des Typs. SHIFT + OSC EDIT 1 = DRUCK.
  • Silberne Regler = Spiel-Regler (CUTOFF, RESONANCE, EG INT, ADSR, PITCH, OSC EDIT, SPEED, DEPTH, LEVEL, PAN, IFX EDIT). Dunkle Regler = Auswahl (TYPE, SAMPLE, EQ, Röhre).
  • SAMPLE-Regler (der zuletzt gedrehte von SAMPLE/TYPE spielt), PITCH (SHIFT = GLIDE), START POINT = Sample-Start.
  • AMP EG · ADSR: ATTACK, DECAY, SUSTAIN, RELEASE = X-Achse (Zeit), mit SHIFT = Y-Achse: Attack-Pegel, Decay-Pegel, Sustain-Pegel, Release-Kurve. SUSTAIN ohne SHIFT = Zeit vom Decay- zum Sustain-Pegel. Drehen öffnet EG EDIT im Display (9 Punkte zum Ziehen inkl. Delay, Hold, Kurven).
  • FILTER: TYPE, RESONANCE, EG INTENSITY, CUTOFF (SHIFT + TYPE = TRACK). MODULATION: TYPE, SPEED, EG TIME (Zeit der EG-Typen), DEPTH.
  • PARAMETRIC EQ: LOW, MID, HIGH (Gain), FREQUENCY (Frequenz des gewählten Bands), MIX. BANDWIDTH an = die Regler stellen die Bandbreite ein, bis BANDWIDTH wieder gedrückt wird (LOW/HIGH ganz links = Shelf). Drehen öffnet die EQ-Seite im Display – dort Punkte ziehen, Preset und BW antippen. SHIFT + BANDWIDTH = Preset: 30 Hz + 18 kHz Cut, 40 Hz + 18 kHz Cut, Old Telephone, Kick.
  • TUBE (pro Part): TUBE ON (SHIFT = alle Parts), TUBE MIX, DRIVE A, DRIVE B. OUTPUT: MASTER, PHONES. 3 × ECC82 unter der Haube.
  • MIX: SIDECHAIN (SHIFT = Quelle), GLUE DRIVE, darunter BASS GLUE, MASTER FX SEND, ROLL SEND, OCTAVE SEND. INSERT FX: TYPE, EDIT, darunter ◀ SELECT, 1–5 (an/aus), SELECT ▶.

Im Menü (kein Platz auf dem Panel)

  • PATTERN SET: BPM, MFX TYPE, ROLL TYPE, MOTION PLAY, ACCENT, Swing, Length, Beat, Key, Scale, Chord Set, Gate Arp, Chain …
  • PART EDIT: WAVE, AMP EG an/aus, SUSTAIN, RELEASE, EG DELAY, EG HOLD, DRUCK, OCTAVE SEND, EQ PRESET, EQ DRIVE, HIGH CUT, LOW CUT, STRETCH LENGTH in Steps, Loop Every, Glide, Oktave …
  • STEP EDIT (ganz im Menü), SAMPLE EDIT (Start, End, Loop, Level, Tune, Reverse, Punch), PART UTILITY (Copy, Clear, Fill All Parts …), INPUT (Audio-In, Sample 1 Bar), GLOBAL (Metronom, TX Character …).

Touchpad & Sync

  • Touchpad mit 4 Tasten: GATE ARP, TOUCH SCALE, MASTER FX, HOLD. MIDI, Clock, Audio-In über die Leiste oben.
